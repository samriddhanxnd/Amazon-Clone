# Amazon Clone

A single-page **Amazon.in homepage clone** built using **HTML and CSS**.

## Features

* Amazon-style header with logo, search bar, account, orders and cart
* Navigation bar with product categories
* Great Indian Festival deals section
* Product cards with prices, discounts and bank offers
* Previously viewed products
* Recommended deals
* Electronics, Fashion and Home & Furniture sections
* Amazon-style footer with multiple links
* Responsive design for different screen sizes

## Technologies Used

* HTML5
* CSS3
